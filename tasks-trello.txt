# Tareas para Backend de Escuela de Fútbol

---
## 0. Dependencias y Comandos de Instalación
```bash
# Instalar todas las dependencias
npm install

# Dependencias principales
npm install express cors dotenv pg sequelize

# Dependencias para Swagger
npm install swagger-jsdoc swagger-ui-express

# Dependencia de desarrollo
npm install --save-dev nodemon
```

| Paquete               | Descripción                                  |
|-----------------------|----------------------------------------------|
| `express`             | Framework para API REST                      |
| `cors`                | Permitir solicitudes externas                |
| `dotenv`              | Cargar variables de entorno                  |
| `pg`                  | Driver de PostgreSQL                         |
| `sequelize`           | ORM para bases de datos                      |
| `swagger-jsdoc`       | Generar documentación Swagger                |
| `swagger-ui-express`  | UI de Swagger                                |
| `nodemon`             | Reinicio automático del servidor             |
